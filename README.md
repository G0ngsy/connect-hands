# 🤟 CONNECTING HANDS
> **실시간 MediaPipe Holistic 관절 추출 및 로컬 LLM 기반 지능형 수어 통역 서비스**


## 1. 프로젝트 개요 (Overview)
* **핵심 가치**: 수어의 단어 나열을 단순 텍스트가 아닌, **인공지능(LLM)**을 통해 상황에 맞는 자연스러운 한국어 문장으로 통역하여 농인과 청인의 소통 격차를 해소합니다.
* **차별점**: 클라우드 API 의존도를 낮추고 **RTX 4070** 자원을 활용한 **로컬 AI (EXAONE 3.5)**를 탑재하여 보안성과 무제한 호출 성능을 확보했습니다.


## 2. 시스템 아키텍처 (Architecture)

### 🏗️ 전체 데이터 흐름
`Frontend (영상 추출)` → `Backend (데이터 수신)` → `AI 추론 (수어 인식)` → `LLM (문장 교정)` → `Frontend (결과 출력)`

* **Frontend**: `React` + `TypeScript` + `Tailwind CSS` (웹소켓 기반 실시간 데이터 렌더링)
* **Backend Server**: `FastAPI` (Uvicorn을 통한 고성능 비동기 통신)
* **AI 추론 엔진**: `TensorFlow` (LSTM 수어 인식) + `Ollama` (EXAONE 3.5 문장 생성)
* **데이터 처리**: `MediaPipe Holistic` (177개 핵심 관절 데이터 추출)

## 3. 핵심 기술 및 데이터 파이프라인

### ① 데이터 정제 (Feature Engineering)
* **최적화**: 전체 좌표(468개+) 대신 얼굴(17개), 양손(42개), 상체(12개) 등 **총 177개 핵심 좌표**만 추출.
* **효과**: 연산 부하 **70% 이상 감소** 및 학습 효율 극대화.
* **Normalization**: 손목 좌표를 기준점(Origin)으로 삼아, 카메라와의 거리에 상관없이 일정 수치 유지.

### ② 동작 인식 알고리즘 (Deep Learning)
* **시계열 분석**: 수어의 '흐름'을 파악하기 위해 **30프레임(약 1초)** 단위의 데이터를 사용.
* **모델**: `LSTM(Long Short-Term Memory)` 신경망을 통해 동작의 전후 맥락 파악.

### ③ 로컬 LLM 문장 생성 (Generative AI)
* **모델**: `LG EXAONE 3.5 (7.8B Parameter)`
* **기능**: 단어 나열(나 + 너 + 만나다)을 전문 통역사 수준의 문장(만나서 정말 반갑습니다)으로 변환.
* **커스텀**: 사용자가 **문체의 정중함(3단계)**을 직접 선택 가능.


## 4. 주요 기능 및 최적화 로직

| 기능 | 상세 설명 |
| :--- | :--- |
| **골반 안전장치** | 손목이 골반보다 아래에 있을 경우 추론 엔진을 일시 정지하여 오작동 방지 |
| **프레임 스로틀링** | 5프레임당 1회 추론 및 `asyncio` 비동기 처리로 GPU 부하 최적화 |
| **자동 세션 리셋** | 손을 내리고 10초 대기 시, 이전 문장 기록을 삭제하여 새 대화 환경 제공 |


## 5. 프로젝트 성과
* **성능**: RTX 4070 환경에서 문장 생성 속도 **0.5초 이내** 달성.
* **UX**: 실시간 스켈레톤(Skeleton) 피드백 제공으로 직관적인 사용자 경험 확보.
